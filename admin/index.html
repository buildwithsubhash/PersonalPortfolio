Paste a GitHub fine-grained personal access token that can write to this repository. It stays in this browser and is only ever sent to api.github.com.

How do I create a token?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: only select repositories → pick this portfolio repo.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Set an expiry, generate, copy the token and paste it above.
